# Still-water study asset

`src/assets/images/water-still-texture.png` was created with the built-in image generation tool on 21 October 2026, using Frank's supplied water image as a material and colour reference. The source reference was not modified.

The selected texture is opaque and bubble-free. A separate static SVG mask and highlight create the clean waterline; CSS circles supply the animated bubbles. The earlier transparent edits had waterline artifacts and are not used by the site.

## Final generation prompt

Create a production website water texture using the input as a color and material reference. Output a COMPLETELY OPAQUE rectangular swatch of ONLY the smooth blue underwater body filling EVERY pixel of the frame, edge to edge. NO waterline or surface edge, NO sky or background above, NO transparency anywhere. No bubbles, droplets, foam, particles or white spots. Wide horizontal banner aspect ratio about 3:1. Preserve the reference's luminous soft translucent-looking blue material, cyan across the top grading to a gently richer medium blue at the bottom, subtle broad diffuse underwater light texture, soft low contrast. The top edge must be blue water, not white, and the bottom edge blue water. This swatch will be clipped to a separate clean wave shape in CSS. No objects, text or borders.
